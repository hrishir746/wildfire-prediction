================================================================================
                            TRAINING OPTIONS
================================================================================

QUICK TEST (5 minutes):
    python scripts/train_with_dashboard.py --epochs 10 --samples 100 --grid-size 128

PRODUCTION (30-60 minutes on GPU):
    python scripts/train_with_dashboard.py --epochs 50 --samples 1000 --grid-size 512

HIGH ACCURACY (2-4 hours on GPU):
    python scripts/train_with_dashboard.py --epochs 100 --samples 2000 --grid-size 512

CUSTOM OPTIONS:
    --epochs 50           Number of training epochs
    --samples 1000        Number of synthetic samples to generate
    --grid-size 512       Grid resolution (512x512 recommended)
    --batch-size 4        Batch size (reduce if GPU memory limited)
    --lr 5e-4             Learning rate
    --val-split 0.2       Validation split ratio (20%)
    --save-samples 5      Number of validation samples to save for viz

================================================================================
                           TROUBLESHOOTING
================================================================================

PROBLEM: Dashboard shows "No training metrics found"
SOLUTION: Make sure you're running train_with_dashboard.py, not other scripts
          Check that outputs/training_metrics.json exists

PROBLEM: Dashboard not updating
SOLUTION: Enable "Auto-refresh (5s)" in sidebar
          Or click "Refresh Now" manually
          Verify training script is still running

PROBLEM: No validation samples for visualization
SOLUTION: Increase --save-samples parameter (e.g., --save-samples 10)
          Check outputs/validation_samples/ directory exists

PROBLEM: GPU out of memory
SOLUTION: Reduce batch size: --batch-size 2 or --batch-size 1
          Or reduce grid size: --grid-size 256
          Close other GPU applications

PROBLEM: Encoding errors on Windows
SOLUTION: Should be automatic! Scripts configure UTF-8 automatically
          If issues persist: set PYTHONIOENCODING=utf-8 in terminal

================================================================================
                          PERFORMANCE TIPS
================================================================================

FOR FASTER TRAINING:
    ✓ Use GPU (20-50x faster than CPU)
    ✓ Increase batch size (if GPU memory allows)
    ✓ Use smaller grid for testing (128x128)
    ✓ Reduce samples for quick iterations (100-200)

FOR BETTER ACCURACY:
    ✓ Train longer (50-100+ epochs)
    ✓ Use more samples (1000-2000+)
    ✓ Keep 512x512 resolution
    ✓ Monitor IoU/Dice convergence
    ✓ Save periodic checkpoints

FOR DEBUGGING:
    ✓ Check training_metrics.json directly
    ✓ Verify validation samples exist
    ✓ Use Predictions tab to see what model learned
    ✓ Compare checkpoints in Checkpoints tab

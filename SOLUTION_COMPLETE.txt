PROBLEM
=======================================================================

UnicodeEncodeError: 'charmap' codec can't encode character...

The Rovo Dev extension spawns child processes with Windows-1252 
encoding instead of UTF-8, causing Unicode characters to fail.

=======================================================================
SOLUTION
=======================================================================

TWO-PRONGED APPROACH:

1. SAFE WRAPPER SCRIPT
   File: scripts/run_training_safe.py
   - Forces UTF-8 encoding before any imports
   - Sets multiple environment variables
   - Works with Rovo Dev child processes

2. UNICODE TO ASCII REPLACEMENT
   - Replaced ~60 Unicode characters in 18 scripts
   - Examples: checkmark -> [OK], degree -> deg, arrow -> ->
   - Backups created automatically

=======================================================================
ROLLBACK PROCEDURE
=======================================================================

To restore original files with Unicode:

RESTORE ONE FILE:
  cd scripts
  Copy-Item agent_app.py.unicode_backup agent_app.py

RESTORE ALL FILES:
  cd scripts
  Get-ChildItem *.unicode_backup | ForEach-Object {
    $original = $_.Name -replace '.unicode_backup$', ''
    Copy-Item $_.Name $original -Force
  }

Note: Unicode encoding issues will return after rollback.
Only rollback if you have a different solution.
